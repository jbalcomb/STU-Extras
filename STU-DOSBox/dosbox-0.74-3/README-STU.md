# STU-DOSBox overlay for DOSBox 0.74-3

This is not a full DOSBox tree. It holds only the files that differ from or are
added to the stock `dosbox-0.74-3.tar.gz` release, laid out at their real paths.

## Build

```sh
tar xzf dosbox-0.74-3.tar.gz
cp -a STU-DOSBox/dosbox-0.74-3/. dosbox-0.74-3/
cd dosbox-0.74-3
rm stu-dosbox-stock-changes.patch README-STU.md
./autogen.sh
./configure --enable-debug=heavy CFLAGS=-w \
    'CXXFLAGS=-g -O2 -std=gnu++98 -DNCURSES_INTERNALS -fpermissive -w'
make -j"$(nproc)"
```

## Contents

- Modified stock files: `configure.ac`, `src/Makefile.am`, `src/libs/Makefile.am`,
  `src/misc/Makefile.am`, `src/dosbox.cpp`, `src/cpu/core_normal.cpp`,
  `src/debug/debug_gui.cpp`, `src/dos/dos.cpp`, `src/hardware/keyboard.cpp`,
  `src/ints/mouse.cpp`.
  `stu-dosbox-stock-changes.patch` shows these changes as a unified diff against stock.
- New probe/capture code: `src/misc/og_sort_trace.h` (includes `gd_decode_record`),
  `src/misc/capture_state.cpp`, `src/misc/og_ci.{cpp,h}`, `src/misc/dosbox_lua.cpp`,
  `include/dosbox_lua.h`.
- Field maps generated by `../gen-fieldmap.py`: `src/misc/gd_*_fields.h`.
  ReMoM keeps identical copies in `MoM/src/`.
- Vendored Lua 5.4.7 (MIT): `src/libs/lua/lua-5.4.7/`, built through `src/libs/lua/Makefile.am`.
- Notes: `CAPTURE_*.md`, `src/misc/og_overlay_*.md`.

Left out on purpose: build output, generated autotools files (`aclocal.m4`, `configure`,
`Makefile.in`), and the local `.claude/` folder and `.code-workspace` file.
